# Game Design Document

## Overview

Poppy Playtime Inspired is a horror-puzzle game set in an abandoned toy factory.

## Game Mechanics

### Core Gameplay

1. **Exploration** - Navigate through different factory areas
2. **Puzzle Solving** - Solve environmental puzzles to progress
3. **Resource Management** - Manage limited resources
4. **Stealth/Evasion** - Avoid or evade threatening entities

## Story Elements

- **Setting:** An abandoned toy manufacturing facility
- **Atmosphere:** Dark, eerie, mysterious
- **Narrative:** Uncover the secrets of the factory
